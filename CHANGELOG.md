# Changelog
## 1.0.0 — 2026-11-08
- Painball: single-player top-down arena paintball for mobile and desktop web.
- 30+ procedurally generated, point-symmetric arenas (portrait and landscape), endless campaign, daily arena + streak.
- Bots with four personalities and tunable skill; best-of-3 matches; 1v1 up to 4v4.
- Persistent paint (your art), share-as-PNG, cosmetic palettes (colour-blind safe), power-ups (shield, rapid, splash).
- Twin-stick touch controls with soft aim assist; keyboard + mouse on desktop.
- PWA/offline, versioned save, accessibility (axe clean, reduced motion). No ads, no tracking.
